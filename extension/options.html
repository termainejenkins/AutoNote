AutoNote options

Before page text is sent

AutoNote does not send a page to Gemini until you confirm this notice. Auto notes stay off until you turn them on.

  • Generate note, and auto notes after the time and scroll thresholds, send the page URL, title, headings, and extracted text (up to 12,000 characters).
  • That request goes only to Google Gemini, using the API key stored in Chrome on this device. The key is not synced.
  • Password fields, browser pages, and the default blocklist are skipped: mail, banking, payments, government sites, and checkout, cart, login, or account paths.

Gemini API key

Paste your own key. AutoNote stores it with chrome.storage.local on this device only. It is never written into the repository.

The field is masked. Create a key in Google AI Studio. Test key sends one small request to Gemini only after you click it. That request asks for a single page of model names. It does not send page content.

Reading and auto notes

Defaults are Study 45 seconds and 60% scroll, Skim 20 seconds and 40% scroll. Time counts only while the tab is visible and you have moved the mouse, scrolled, or typed in the last minute. A short page that does not scroll counts as fully scrolled.

Off by default. When on, Chrome asks permission to read http and https pages, and one note is saved per page per day after the threshold. Turning this off removes that site access.
